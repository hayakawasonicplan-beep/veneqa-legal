VENEQA Mobile User Guide

English · Applies to VENEQA Mobile Pro and VENEQA Mobile (Lite)
Last updated: 3 August 2026

VENEQA Mobile is an on-device measurement app for live spectrogram and RTA (Decay fill + Avg line). It is designed for sound-system work on iPhone — walkaround checks, relative spectrum, and (Pro) sending averaged traces to the VENEQA desktop app on the same local network.

Analysis features are the same. Lite hides the phone / send controls and the Settings sections for PC destination and send mode.

2. First launch

  1. Open the app on a real iPhone (simulator can show UI; real mic behaviour is best on device).
  2. Allow Microphone access when iOS asks.
  3. Tap ▶ if analysis is paused (the app starts shortly after open).
  4. Optional: open Settings (gear) to set FFT size, mic position, and SPL trim.
Pro only: When you first send to a Mac/PC, allow Local Network if iOS prompts. Without that permission, UDP send will fail.

3. Screen layout

RegionWhat you see
Top Spectrogram — time vs frequency colour map from the phone mic.
Bottom RTA — Decay fill (peak hold) plus Avg line (exponential average).
Toolbar Smoothing / times, Reset Avg, (Pro) phone send panel, Play / Pause.
Portrait Plots stacked; toolbar along the bottom.
Landscape Plots on the left; toolbar along the trailing edge.

Drag the spectrogram dB range (left edge) to match the level of what you are looking at. Crosshair readouts follow the cursor on the plots.

4. Toolbar controls

Menus

ControlMeaning
RTA (1/3 … 1/48, No) Fractional-octave smoothing for the Decay fill. No is raw FFT bins.
Dec (0.1s … 4.0s) Decay hold time for the filled envelope.
Avg (smoothing) Display smoothing for the Avg line. Cannot be finer than Decay smoothing.
Avg (3s … 15s) Time constant (τ) for the exponential average.

Buttons

  • Reset Avg — clears the running average so a new Avg builds from that moment.
  • Phone (Pro) — opens / closes the Remote → PC send panel.
  • Play / Pause — starts or pauses live analysis (pause glyph blinks while paused).

5. Settings

Open Settings from the header gear icon.

Analysis

  • Sample Rate — shown read-only (from the active audio session).
  • FFT Size — 8192 / 16384 / 32768. Larger FFT → finer frequency resolution, slightly more latency/CPU.

Spectrogram

  • Colormap — VENEQA, Warm, Hellfire, Frost, Emerald, Bloom, Neon (aligned with desktop Show).

Microphone

  • Position — Bottom / Front / Back (by data source). All use measurement mode (less system HPF/AGC).
  • Changing position restarts the mic — re-check SPL Trim afterward.

RTA Level

  • SPL Trim — ±20 dB trim on top of the built-in +120 dB base (dBFS → approximate SPL readout).
  • Readout colour thresholds — green / yellow / red levels for the meter-style readout (same idea as the PC SPL Meter).
Built-in mics are not calibrated absolute SPL meters. Use trim for relative work or rough alignment against a known reference; do not treat the number as certified SPL.

About / Legal

Settings → About shows app name and version, and opens Privacy Policy / Terms of Use in Safari.

6. Pro: link to VENEQA on Mac/PC

Pro can talk to desktop VENEQA over UDP on your local network (same Wi‑Fi or Personal Hotspot). Default port is 5005.

One-time setup

  1. On the Mac/PC: open VENEQA → Preferences → Remote → enable remote access. Status should show Listening…
  2. Note the IP address shown there (Hotspot is often 172.20.10.x — use the exact value).
  3. On the phone: Settings → PC Destination — enter that IP and port 5005.
  4. Settings → Send Avg → PC:
    • Replace same name — fixed point name (e.g. L / R); each send overwrites that Mobile inbox trace.
    • New each send — walkaround mode: base-01, base-02, … after each successful send.
  5. Allow Local Network when prompted.

Send panel (phone icon)

ActionWhat it does
PC Space (TF / RTA capture) Same as pressing Space on the desktop: Tuning captures live TF; Show captures RTA Avg. Measurement uses the PC mic/ref — the phone does not measure TF itself.
Avg → PC Sends the phone’s current RTA Avg curve to desktop Show → Mobile inbox (not a TF measurement). PC RTA Play is not required to receive it.

7. Measurement tips

  • Hold the phone steadily; aim the selected mic toward the source or room you care about.
  • Use longer Avg τ (10–15 s) for a stable walkaround curve; shorter for quicker response.
  • Reset Avg when you change position or program so old energy does not pollute the average.
  • For Pro walkarounds, prefer New each send and a short base name (e.g. A, FL).
  • Keep phone and Mac on the same LAN; avoid guest Wi‑Fi that blocks device-to-device traffic.

8. Troubleshooting

SymptomWhat to try
No spectrum / silence Check Mic permission; try another Mic Position; confirm Play is not paused; unmute the source.
Level looks wrong Adjust SPL Trim; check dB range on the spectrogram; remember built-in mics are uncalibrated.
Pro send fails Confirm Remote Listening on PC, correct IP/port, same network, Local Network allowed. Status text on the send panel shows success or failure.
Nothing in Mobile inbox Use Avg → PC (not only Space). Space captures on the PC inputs, not the phone Avg.
App sleeps / gaps Keep the screen awake while measuring; backgrounding may interrupt capture.
